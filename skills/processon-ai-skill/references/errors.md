# 错误处理、重试规则与能力边界

> 本文件仅在**工具调用失败、需要重试、用户请求超出能力范围**时读取。正常调用不需要读本文件。
>
> 下文链接中的 **`{BASE}` = 当前环境的站点根**（正式 / 灰度等，由 `PO_ENV` 或包内默认环境决定），实际值取自 `node scripts/get-token.mjs processon_env_info` 的 `LINK_*`（整条链接可直接照抄）；**`{CHANNEL}` = 本包对应的载体来源**（打包时已注入，读到即实际值）。**不得硬编码域名**，详见 `references/tracking.md`。

---

## 重试与放弃（硬上限）

> **同一个生成/编辑任务，累计最多尝试 2 次**（首次 + 重试 1 次）。第 2 次仍失败即停止**写操作**，转为友好告知；只读工具（如取回文件链接用的查询）仍可调用。

- 计数以**用户的一个请求**为单位：无论失败发生在生成图数据还是落库/更新哪一步，两步合起来只有 2 次机会。
- **只计写操作**：`generatedDsl`、`createProcessOnFile`、`updateProcessOnFile` 的尝试计入次数。`orchestrator.mjs` / `mindcreate.mjs` 内部含上述工具，同样计入。
- **只读操作不计入**：`queryProcessOnFile`（含重试前的查重）、`check`、`scripts/get-version.mjs` 不消耗重试余量，可按需调用。
- **任何形式的再次尝试都计入，包括以「排查」「验证」「试一下」为名的调用。** 以下改动后重新调用**一律计入**，不得视为新任务：
  - 换 theme / structure / category
  - 换编码方式、缩短或简化内容
  - 增删参数（如为满足 schema 补传 `reqId`）、换措辞、换写操作工具
- **禁止把失败当作待排查的技术问题**。连续 2 次失败即视为服务暂时不可用，直接按下方处理转交用户。
- **每次写操作失败后，第一件事就是检查失败返回中的错误码是否为 `61685`**（后端明确返回 `61685` = AI 点数不足，重试也不会成功，须尽早识别）：
  1. **错误码为 `61685`** → 明确判定为 AI 点数不足，**不重试**。
  2. **判定为点数不足后**，根据用户身份直接给出对应购买链接：
     - **免费用户**（文案含「会员」「升级」字样，或无法确定身份时默认按免费用户）→ 给出付费链接：`{BASE}/setting?paytype=personal&source=processon_skill&payPointSource={CHANNEL}`；另可提示思维导图不消耗点数。
     - **个人版会员**（文案仅含「点数」「不足」「已消耗」，**无**「会员」「升级」字样）→ 给出 AI 点数购买链接：`{BASE}/setting?paytype=aipoint&source=processon_skill&payPointSource={CHANNEL}`；另可提示思维导图不消耗点数。
  3. **非点数不足的失败**（错误码非 `61685`）→ 按原重试逻辑处理。达到上限后的常规兜底：
     - **新建失败** → 友好说明未能生成成功，建议稍后再试，或引导用户到 ProcessOn 官网自行创建（此时无文件信息可给）。
     - **编辑失败** → 查该文件信息，给出文件名 + 文件链接 + 文件缩略图链接，引导用户到官网手动编辑。
- 鉴权失败（`-32001`）与工具未注册属于**配置问题**，按 `references/auth.md` 授权/注册后的那次调用不计入上述 2 次。
- **配置/授权自身也有 2 次上限**：见 `references/auth.md`「MCP 注册与配置（三层降级）」。
- 告知用户时不得呈现原始报错或错误码，也不要说明重试了几次。

### 重试安全性

| 操作 | 重试是否安全 | 说明 |
|------|------|---------|
| `queryProcessOnFile` | ✅ 安全 | 只读，无副作用，可反复调用 |
| `orchestrator.mjs`（流程图新建） | ❌ 不可盲目重试 | 内部含 `createProcessOnFile`，每次调用都会新建文件。重试前先 `queryProcessOnFile` 查重 |
| `orchestrator.mjs`（流程图编辑） | ⚠️ 有副作用但可重试 | 内部含 `updateProcessOnFile`，整体覆盖同一文件，结果以最后一次为准 |
| `mindcreate.mjs`（思维导图新建） | ❌ 不可盲目重试 | 内部含 `createProcessOnFile`，每次调用都会新建文件。重试前先 `queryProcessOnFile` 查重 |
| `mindcreate.mjs`（思维导图编辑） | ⚠️ 有副作用但可重试 | 内部含 `updateProcessOnFile`，整体覆盖同一文件，结果以最后一次为准 |
| `b64.mjs` + 单步 `updateProcessOnFile`（流程图情况一） | ⚠️ 有副作用但可重试 | 整体覆盖同一文件，结果以最后一次为准 |

### 交付验证

| 操作 | 成功判定 | 展示给用户 |
|------|---------|-----------|
| 新建 | 返回含 chartId 与文件链接 | 文件名 + 类型 + 文件链接 + 文件缩略图链接（点数大于 0 时另加） |
| 编辑 | 返回含文件链接 | 文件名 + 类型 + 文件链接 + 文件缩略图链接 + 「历史版本可查」提示（点数大于 0 时另加） |
| 查询 | 返回文件列表 | 每条：文件名 + 类型 + 文件链接 + 文件缩略图链接 |

## 错误速查

| code / 特征 | 原因 | 处理方式 |
|---------|------|---------|
| `-32001` | apiKey 缺失或失效 | 走 `references/auth.md` 授权流程后重试；两次仍失败则按三层降级交出手动配置信息 |
| `401` | apiKey 无效或未配置 | 同上 |
| `815` | 需升级会员 | **不重试**。友好告知需开通会员，给出开通链接 `{BASE}/setting?paytype=personal&source=processon_skill&payPointSource={CHANNEL}` |
| **`61685` AI 点数不足（免费用户）** | 后端返回 `61685`，文案含「会员」「升级」字样或身份不明 | **不重试**。给出付费链接 `{BASE}/setting?paytype=personal&source=processon_skill&payPointSource={CHANNEL}`；另可提示思维导图不消耗点数 |
| **`61685` AI 点数不足（VIP 会员）** | 后端返回 `61685`，文案仅含「点数」「不足」「已消耗」，无「会员」「升级」字样 | **不重试**。给出 AI 点数购买链接 `{BASE}/setting?paytype=aipoint&source=processon_skill&payPointSource={CHANNEL}`；另可提示思维导图不消耗点数 |
| `404` | 未找到该文件 | 确认 chartId/文件名是否正确；编辑前先用查询确认文件存在 |
| `510` | 后端调用失败 | 最多再试 1 次；仍失败则友好告知用户稍后再试 |
| 查询无结果 | 无匹配文件 / 关键词过精确 | 友好提示，建议更换关键词 |
| 跨会话无原内容 | 上下文无该图 DSL | 走编辑情况二：先 query 拿 chartId/category，再 `generatedDsl`（带 chartId）重新生成 |
| 编辑时 `generatedDsl` 报错 | 生成失败 | 查该文件信息，把 文件名 + 文件链接 + 文件缩略图链接 给用户，引导其到官网手动编辑 |
| 新建失败 | 生成或落库失败 | 累计 2 次内可重试；达上限则友好告知，引导用户到官网自行创建 |
| 请求超时/异常 | 网络或后端异常 | 累计 2 次内可重试（新建重试前先查询是否已创建）；达上限则友好告知 |
| 内容过长 / 生成超时 | 需求过于庞大 | 不盲目重试。友好说明内容偏多，建议拆分成几张图分别生成，或缩减层级与节点数量后重试 |
| 解码失败 / 内容异常 | 通常内容过长导致 heredoc 传递异常 | **不要按常规失败重试**。友好说明内容篇幅较长可能影响保存，建议精简或压缩后再试，也可拆分。**不得提及字符数、长度上限、编码等技术细节** |
| 重名文件 | 账号中已有同名文件（**不影响创建**） | 新建照常进行，无需改名或询问。仅在编辑时若查询命中多个同名文件，向用户列出候选让其确认改哪一张 |
| 工具不存在 / 报错含 `version`、`incompatible`、`deprecated`、`not_supported` | 本地 Skill 版本与服务端不匹配 | **不要反复换参数重试**。友好告知当前版本可能过旧，给出下载地址（见下文「Skill 版本更新」） |

## 能力边界与超出边界时的回应

**本 Skill 只做四件事**：**新建文件**、**编辑文件内容**、**查询文件**、**导出文件**。图形类型只支持流程图类与思维导图类。编辑仅限文件内容（整体覆盖）；文件属性（标题、文件夹位置、权限、分享设置等）一律不支持修改。

**语气要求**：先说明「暂时还不支持」，再给出可行的替代路径。不得仅以"不支持"作答后结束，也不得忽略该请求。

| 用户可能的请求 | 处理 |
|---------|------|
| **改标题** | 说明暂时不支持修改标题，提供文件链接，引导用户自行重命名。**`updateProcessOnFile` 的 `title` 传新值也不会生效**，不要据此告诉用户已改 |
| **删除文件** | 说明暂时不支持代为删除，先用查询定位文件，提供文件链接，引导用户自行删除 |
| **移动 / 指定文件夹** | 说明新建会落在根目录、暂时不能移动，创建完成后可自行整理；**仍照常创建，不要因此中断** |
| **分享 / 改权限** | 说明暂时还不支持，给出文件链接，引导其在 ProcessOn 中完成 |
| **局部修改** | 内容可以改，但会整体覆盖。照常改动并更新，完成后告知原内容已存为历史版本 |
| **查看图的内容/结构** | 查询只返回文件名与链接。给出文件链接，请其打开查看 |
| **一次要多张图** | 先完成第一张，再提示「如还需要其他图，请再说一次」，逐个处理 |
| **其他非上述四项的操作** | 说明暂时还不支持，把相关文件链接给用户，引导其在 ProcessOn 中自行处理 |

> 措辞示例（改标题）：「目前我还不能直接帮你改文件标题。你可以打开这个文件自己重命名：<文件链接>」
> 措辞示例（删除）：「暂时还不支持代为删除文件。这是你要找的那张图：<文件链接>，打开后可在页面中删除。」
> **共同要点**：能力范围内的部分照常执行；超出范围的部分提供文件链接，使用户有明确的后续路径。

## Skill 版本更新

`node scripts/get-version.mjs` 输出的 `STATUS:UPDATE_AVAILABLE` 表示线上已有更新版本（脚本同时给出 `CURRENT` / `LATEST` / `UPDATED_AT` 与 `CHANGELOG`）。此时**附一句友好提示即可**：说明有新版本，把 `CHANGELOG` **以无序列表按脚本给出的顺序原样列出**，再给出下载地址。**不得因版本旧拒绝执行任务**，`UP_TO_DATE`、`VERSION_CHECK_SKIPPED:*` 一律静默。

- 下载地址：`https://pocdn.processon.com/agent/processon_skill.zip`（**本包对应的下载地址，已随包注入**，渠道包会自动变成本渠道的 zip，直接原样给出即可）
- 更新方式：下载解压替换 Skill 目录，再执行 `node scripts/get-token.mjs processon_check_and_start_auth` 刷新配置（保留原有授权）。
- 版本不匹配类报错的处理见上文「错误速查」表最后一行。
