# 查询文件 queryProcessOnFile

> 按关键词查找用户 ProcessOn 账号下的文件，返回所有匹配文件的名称与链接。

## 功能说明

在用户账号下按关键词查找文件，后端返回全部匹配项；每项含文件名称、ProcessOn 文件链接、文件缩略图链接。不分图类型，不返回文件内部结构。

## 适用场景

- 用户要查找、搜索、整理自己的 ProcessOn 文件。
- 编辑「情况二」（跨会话、手上无 DSL）时，被按需调用来定位文件（见 `references/edit.md`）。

查询是**独立能力**，本身支持「按关键词找文件」的需求，不依附于编辑。

## 操作约束

- **前置检查**：必须已完成 apiKey 校验（见 `references/auth.md`）。查询的是该用户自己账号下的文件，必须有有效 apiKey。
- **不分图类型**：流程图与思维导图都查，不按类型过滤。
- **全部列出**：后端返回的所有匹配文件，直接全部列给用户，不截断。
- **不返回内部结构**：只返回文件名与链接，不读取图的内部内容。
- **查不到结果**：做友好提示，建议更换关键词。

**重试安全性**：安全 — 只读操作，无副作用，可反复调用（不计入重试次数）。

## 数据流转

```
用户："找一下我那张 XX 图"
  → node scripts/query.mjs title='XX'
  → 后端在该用户账号下按文件名搜索
  → 后端返回所有匹配文件（每条含 文件名 + 类型 + chartId + 文件链接 + 文件缩略图链接）
  → 有结果：全部列给用户（文件名 + 类型 + 文件链接 + 文件缩略图链接；chartId 内部留存不展示）
    无结果：友好提示，建议更换关键词
```

## 工具调用

```
node scripts/query.mjs title='<文件名关键词>'
```

> `title` 为短参数，直接写值即可；含空格或特殊符号时按平台加引号（mac/Linux 单引号、Windows 双引号，同 SKILL.md「工具调用方式」）。

## 参数说明

| 参数 | 必填 | 说明 |
|------|------|------|
| `title` | 是 | 文件名关键词。后端在该用户账号下按文件名搜索，返回全部命中项（不分图类型） |

## 返回给用户

匹配文件列表，每条：

| 字段 | 说明 |
|------|------|
| 文件名 | 匹配文件的名称 |
| 类型 | 流程图 / 思维导图（后端按 `categoryParent` 判定：`flow`=流程图，否则思维导图） |
| 文件链接 | 可在线打开编辑的链接，**完整原样输出纯 URL**，禁止省略、截断 |
| 文件缩略图链接 | 完整原样输出纯 URL，禁止省略、截断 |

**每条的输出模板（`{{...}}` 为占位符，输出时替换为实际值）**：

```
1. **文件名**：{{title}}
   **类型**：流程图 / 思维导图
   **文件链接**：{{文件URL}}
   **文件缩略图**：{{图片URL}}
```

多条时按序号 1、2、3…依次列出。

> 返回中的 `chartId` **仅内部留存**（供后续编辑定位目标文件），**不展示给用户**。

无结果时不返回列表，改为友好提示，例如：「没有找到与『XX』相关的文件，可以换个关键词再试试。」
